# PimPid — ตรวจจับการพิมพ์ผิดภาษา (ไทย ⇄ English)

แอปบน Windows ที่ทำงานอยู่เบื้องหลังและคอยดูว่าคุณพิมพ์อะไรในโปรแกรมไหนก็ได้ ถ้าคุณลืมเปลี่ยนภาษา เช่น
ตั้งใจจะพิมพ์ `สวัสดี` แต่ได้ `l;ylfu` ออกมา จะมีป๊อปอัปเด้งขึ้นมาบอกคำที่ถูกต้อง และกดแก้ได้ทันที

```
ลืมเปลี่ยนภาษาหรือเปล่า?
l;ylfu  →  สวัสดี
เป็นไทย?  กด Ctrl+Shift+Space / Pause / คลิก เพื่อแก้
```

## ติดตั้งบนเครื่องอื่น

ส่งไฟล์ `dist\PimPid.exe` ไฟล์เดียวไปที่เครื่องนั้น (ไม่ต้องมี Python) แล้วดับเบิลคลิก
จะขึ้นหน้าต่างติดตั้ง โดยไม่ต้องใช้สิทธิ์ Administrator

- ติดตั้งไปที่ `%LOCALAPPDATA%\Programs\PimPid` และมีทางลัดใน Start Menu
- เลือกได้ว่าจะให้เปิดอัตโนมัติเมื่อเปิดเครื่อง และจะสร้างทางลัดบนเดสก์ท็อปหรือไม่
- ถอนการติดตั้งได้ที่ Settings → Apps → PimPid
- ติดตั้งเวอร์ชันใหม่ทับได้เลย ตัวติดตั้งจะปิดตัวเก่าให้เอง

ติดตั้งแบบเงียบ (เช่น ใช้แจกหลายเครื่อง):

```
PimPid.exe --install                 :: ติดตั้ง + เปิดพร้อม Windows + เปิดโปรแกรม
PimPid.exe --install --desktop       :: สร้างทางลัดบนเดสก์ท็อปด้วย
PimPid.exe --install --no-startup --no-launch
PimPid.exe --uninstall --silent
PimPid.exe --portable                :: รันเลยโดยไม่ติดตั้ง
```

Windows SmartScreen อาจเตือนตอนเปิดครั้งแรก เพราะไฟล์ไม่ได้เซ็นชื่อดิจิทัล ให้กด "More info" → "Run anyway"

## ทำงานเบื้องหลัง

- ปิดหน้าต่างแล้วโปรแกรมยังทำงานต่อ ไอคอน **กA** อยู่ที่มุมขวาล่างของ taskbar (ถ้าไม่เห็น ให้ดูในลูกศร ^)
- คลิกไอคอนเพื่อเปิดหน้าต่าง คลิกขวาเพื่อหยุดชั่วคราวหรือออกจากโปรแกรม
- ไอคอนเป็นสีเทาเมื่อหยุดชั่วคราว
- ตอนเปิดพร้อม Windows จะไม่ขึ้นหน้าต่าง แต่ทำงานอยู่ใน tray
- การตั้งค่าเก็บไว้ที่ `%APPDATA%\PimPid\config.json`

## Build เอง

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

ได้ไฟล์ `dist\PimPid.exe` (ต้องมี Python 3.8+; สคริปต์จะติดตั้ง pyinstaller, pystray, pillow ให้)

## วิธีใช้ (ตอนพัฒนา)

- ดับเบิลคลิก `run.bat` หรือรัน `pythonw app.py` (ต้อง `pip install pystray pillow` สำหรับไอคอน tray)
- พิมพ์ตามปกติ ถ้าพิมพ์ผิดภาษา ป๊อปอัปจะขึ้นใกล้ ๆ เคอร์เซอร์ (หรือมุมขวาล่างของจอ)
- กด **Ctrl+Shift+Space** หรือ **Pause** หรือ **คลิกที่ป๊อปอัป** แอปจะลบคำที่ผิด พิมพ์คำที่ถูกให้ แล้วเปลี่ยนภาษาแป้นพิมพ์ให้ด้วย

ตัวเลือกในหน้าต่างหลัก:
- **แก้ให้อัตโนมัติเมื่อเคาะ Space** แก้ให้เลยโดยไม่ต้องกดอะไร
- **เปลี่ยนภาษาแป้นพิมพ์ให้ด้วยหลังแก้**
- **เตือนระหว่างพิมพ์** เตือนตั้งแต่ยังพิมพ์คำไม่จบ

ค่าที่ตั้งไว้จะเก็บใน `%APPDATA%\PimPid\config.json` (เปลี่ยน hotkey ได้ที่นี่)

## ทำงานอย่างไร

1. `winhook.py` ติดตั้ง low-level keyboard hook ไว้ดูว่ากดปุ่มไหน (ใช้ตำแหน่งปุ่ม ไม่ใช่ตัวอักษร)
2. `layout.py` แปลงแต่ละปุ่มเป็นทั้งตัวอักษรอังกฤษ (QWERTY) และไทย (เกษมณี)
3. `detector.py` ให้คะแนนว่าแต่ละแบบ "ดูเป็นภาษาจริง" แค่ไหน
   - ไทย: กฎการเขียน (สระหรือวรรณยุกต์ต้องตามหลังพยัญชนะ, สระหน้าต้องมีพยัญชนะตาม ฯลฯ), พจนานุกรม และสถิติอักษรคู่
   - อังกฤษ: พจนานุกรม, สถิติอักษรคู่, มีสระ, ไม่มีสัญลักษณ์หรือตัวเลขปนกลางคำ (`;` `'` `[` `]` คือ ว ง บ ล)
   - ถ้าภาษาอีกฝั่งได้คะแนนสูงกว่าชัดเจน จะถือว่าพิมพ์ผิดภาษา
4. การแก้ใช้ `SendInput` กด Backspace แล้วพิมพ์เป็น Unicode จึงไม่ขึ้นกับภาษาแป้นพิมพ์ที่ใช้อยู่

เพิ่มคำในพจนานุกรมได้ที่ `words_en.txt` / `words_th.txt` (หนึ่งคำต่อบรรทัด) วางไว้ใน `%APPDATA%\PimPid`
(หรือข้างโค้ดตอนพัฒนา) จะช่วยให้แม่นขึ้น

ทดสอบตัวตรวจด้วย `python test_detector.py`

## ข้อจำกัด

- รองรับเฉพาะแป้น US QWERTY กับ ไทยเกษมณี
- แอปไม่รู้ว่าคุณคลิกเมาส์ย้ายเคอร์เซอร์ไปที่อื่น จึงล้างบัฟเฟอร์เองเมื่อเปลี่ยนหน้าต่าง กด Enter/ลูกศร/ปุ่มลัด หรือไม่ได้พิมพ์นานเกิน 15 วินาที
- โปรแกรมที่รันแบบ Administrator จะดักการพิมพ์ไม่ได้ ถ้าแอปเราไม่ได้รันแบบ Administrator ด้วย
- คำสั้นมาก ๆ ที่เป็นคำจริงได้ทั้งสองภาษา (เช่น `ok` = `นา`) จะไม่เตือน
- ข้อมูลที่พิมพ์ไม่ถูกบันทึกหรือส่งไปไหน แอปเก็บไว้แค่คำล่าสุดในหน่วยความจำ
